ENTRY POINTS

三种使用方式

按你的角色选一条路径。绝大多数智能家居玩家选第一种即可。

Home Assistant 集成 推荐

解压即用的自定义组件，设备变成 HA 的开关 / 传感器 / 在线状态实体，直接接入自动化与面板。

  • 多通道开关逐路暴露，名称取 App 昵称
  • MQTT 秒级回推 + 轮询兜底
  • 凭证失效自动弹窗重验，不用重加

Python 客户端 DEV

纯 Python 库，仅依赖 requests / cryptography / paho-mqtt，适合自建脚本与二次开发。

  • 登录 / 设备 / 控制 / 服务调用全接口
  • token 自动刷新与失效重试
  • 增量设备刷新，适合定时巡检

命令行工具 CLI

不写代码即可探测账号下所有设备、下发控制、观察 MQTT 实时回推。

  • probe 假凭证签名探活（无需账号）
  • devices 列出全部设备与属性
  • watch 实时监听状态变化
METHOD 01 · RECOMMENDED

Home Assistant 自定义集成

安装包 bull_iot-ha-1.0.0.zip（22KB），或直接从仓库复制 homeassistant/custom_components/bull_iot/。

解压到 HA 配置目录

在含 configuration.yaml 的目录下执行 unzip bull_iot-ha-1.0.0.zip，得到 custom_components/bull_iot/。

重启 Home Assistant

设置 → 系统 → 重启。首次加载时 HA 会自动安装依赖（requests / cryptography / paho-mqtt）。

添加集成，输入账号密码

设置 → 设备与服务 → 添加集成 → 搜索 Bull IoT。用户名为手机号；密码为 App 内设置的登录密码。

注意：只用手机验证码登录过 App 的账号，需先在 App 内（我的 → 设置 → 账号与安全）设置密码，本集成只支持账号密码登录。

你会得到什么

实体类型示例说明
switch × Nswitch.进门射灯每路通道一个开关，名称取 App 昵称；单键设备暴露总开关

自动化示例

人体传感器联动射灯，人来灯开、3 分钟无人关：

automations.yaml
automation:
  - alias: "玄关人来灯亮"
    trigger:
      - platform: state
        entity_id: binary_sensor.玄关_人体传感器_occupancy
        to: "on"
    action:
      - service: switch.turn_on
        target:
          entity_id: switch.进门射灯

  - alias: "玄关人走灯灭"
    trigger:
      - platform: state
        entity_id: binary_sensor.玄关_人体传感器_occupancy
        to: "off"
        for: "00:03:00"
    action:
      - service: switch.turn_off
        target:
          entity_id: switch.进门射灯
选项默认说明
轮询间隔60 秒15–3600 秒可调；MQTT 在线时是兜底，可调大
MQTT 实时推送开启关闭后仅靠轮询，延迟最高等于轮询间隔
凭证失效—自动重登；彻底失效弹"重新验证"对话框，实体不用重建
METHOD 02 · DEVELOPER

Python 客户端

安装：pip install requests cryptography paho-mqtt，然后把 bull_iot/ 目录拷进你的项目。

quickstart.py
from bull_iot import BullCloudClient

with BullCloudClient() as client:
    client.login("你的账号", "你的密码")

    devices = client.list_devices()
    for d in devices:
        print(d.iot_id, d.name, d.room)

    # 打开 / 关闭设备第一路开关
    client.set_property(devices[0].iot_id, "PowerSwitch", 1)
    client.set_property(devices[0.iot_id, "PowerSwitch", 0)
核心 API说明
login(username, password)账号密码登录，获取 access_token / refresh_token / openid
refresh_access_token()刷新 token；失效时内部自动回退重新登录
list_devices(family_ids=None)遍历所有家庭，返回 Device 列表（含属性快照、型号、固件）
refresh_devices(devices)增量刷新进已有缓存，定时巡检用
get_families() / switch_family(id)家庭列表 / 切换当前家庭
get_device_info(iot_id)单设备详情（型号、固件版本）
set_property / set_properties设置单个 / 批量属性
invoke_thing_service(iot_id, identifier)调用设备服务（如充电桩 SheduleAuth 激活充电）
METHOD 03 · CLI

命令行工具

凭证优先级：--user/--password 参数 > 环境变量 BULL_USERNAME / BULL_PASSWORD > 交互输入。

bash
# 不登录验证签名实现（假凭证探活，无需账号）
python -m bull_iot.cli probe

# 列出全部设备及属性
python -m bull_iot.cli devices

# 控制单个属性（关掉 G27 三位开关第 1 路）
python -m bull_iot.cli set --iot-id <iotId> --identifier PowerSwitch_1 --value 0

# MQTT 实时监听 60 秒（期间按物理开关，观察状态回推）
python -m bull_iot.cli watch --seconds 60
PROTOCOL SUMMARY

协议要点速览

完整推导过程（含每一次踩坑与校准方法）见仓库中的 PROTOCOL.md。

01

x-ca-* HMAC-SHA256

阿里云 API 网关风格签名。表单请求的签名 query 用表单字段本身（网关从 body 重建），且不算 Content-MD5。

02

登录加密

用户名 AES-128-CBC（随机 IV 前缀 + 大写 Hex）；密码 sha256(sha256(pwd)+sha256("GONGNIU")) 双派生。

03

登录请求

x-www-form-urlencoded 提交，必须携带头部 Login_parameter: APP_PWD（大小写敏感，放 body 或 query 均无效）。

04

设备模型

/mos/home/v3/rooms 返回拍平列表；主条目（deviceEntity=true）带昵称，功能实体带通道名；属性拍平为 父.子。

05

属性控制

PUT /mos/v1/dc/setDeviceProperty/{iotId}，body 为 [{"identifier":..., "value":...}]，实测云端接受且回读一致。

06

MQTT 实时通道

emqx-prod.iotbull.com:1883，username=openid、password=access_token、clientId=IOS@2.9.1@<openid>；连接后发布绑定报文，接收 thing.properties / thing.status。

TROUBLESHOOTING

常见问题

只有验证码登录过 App，没有密码怎么办？
在 App 内 我的 → 设置 → 账号与安全 → 设置密码，然后用账号密码登录。本客户端只支持账号密码登录。
为什么开关名字是"进门射灯"这种？
直接取你在公牛智家 App 里给该通道设置的昵称。在 App 里改名后，HA 侧下次刷新自动同步。
设备出现了两次 / 控制的是旧状态？
云端设备会跨家庭共享（实测 1117 条记录 vs 448 台唯一设备），客户端已按 iotId 去重。若状态异常，检查集成选项里 MQTT 是否开启、轮询间隔是否过大。
家庭很多，有些设备看不到？
云端家庭列表接口硬上限 50 条，且忽略一切分页参数、无搜索端点，只能覆盖最近访问的 50 个家庭。这是云端限制，非本客户端问题。
提示需要重新验证（reauth）？
改了密码或 token 彻底失效。按 HA 弹窗输入新密码即可，不需要删除集成重加，实体和自动化都不受影响。
支持充电桩 / 电量统计吗？
充电桩走 invoke_thing_service（如 SheduleAuth 激活充电）；带计量功能的设备会暴露实时功率 / 累计电量传感器。
SECURITY & PRIVACY

安全与隐私

凭证去向

  • 账号密码只存两处：你自己机器上的 .env（客户端，默认 gitignore），或 Home Assistant 的 .storage（集成，删除即清除）
  • 仓库不包含、也不上传任何真实凭证，示例手机号均为虚构测试号
  • 所有网络通信仅与公牛官方云端点发生

风险提醒

  • 通过云端控制大功率设备（充电桩、加热器等）有安全风险
  • 请谨慎配置"无人值守时自动开启大功率负载"的自动化
  • 本项目仅用于个人设备接入与学习研究
